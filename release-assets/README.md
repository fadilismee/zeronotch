# Local release staging

Place the generated installer and its checksum manifest in this folder before
creating a GitHub Release. Files in this directory are ignored by Git, except
for this note.

Expected v1.0.9 files:

- `zeronotch-Setup-v1.0.9.exe`
- `zeronotch-Setup-v1.0.9.json`
- `release-notes-v1.0.9.md`
